# 🌍 Minecraft Seed Finder

A lightweight Electron app that generates and analyzes Minecraft-style world seeds to find interesting terrain patterns.

> This project does NOT connect to Minecraft directly. It simulates seed behavior using mathematical patterns.

---

## 🚀 Features

- Generates large Minecraft-style seed numbers
- Scans seeds for interesting world patterns
- Detects simulated features like:
  - 🏡 Village patterns
  - 🌿 Plains areas
  - ⛰ Mountain regions
  - 🌊 Ocean mix zones
- Simple Electron-based desktop UI
